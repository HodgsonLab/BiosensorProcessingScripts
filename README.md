# BiosensorProcessingScripts
Matlab and Metamorph Scripts for manually processing the ratiometric calculations

Matlab script for morphing calculations:
trackingMorphX.m
This uses particle tracking script sets from John C. Crocker and David G. Grier, originally written as freeware in 1997.

Matlab script for linear translational registration:
regFC2.m, uses subAlign.m and subpixShift.m
This is based on scripts and subroutines originally written by my former colleague Dr. Feimo Shen, who has written many image processing tools for us.
In fact how to code in Matlab, I learned from Dr. Feimo Shen by taking apart his codes and studying how those worked, so there will be a lot of use and reuse of his algorithms and bit and pieces throughout these codes presented here.

Confirmed to work with Matlab version 2011a.  I am sure newer ones will be ok, but not really tested.


Metamorph Journals: Metamorph was discontinued and so these journals are provided as is.  Users are encouraged to try out u-probe platform, available through the Danuser Lab Github page for download.
